Accessible User Guide

Designed for visually impaired DJs and music producers

Introduction to Accessibility in Mixxx

Mixxx includes comprehensive accessibility features designed to make DJ mixing more accessible to visually impaired users. This guide explains how to use these features effectively.

Accessibility Features: Mixxx provides keyboard navigation, screen reader compatibility, high-contrast themes, and enhanced audio feedback for a more inclusive DJ experience.

Getting Started with Keyboard Navigation

Most of Mixxx can be controlled entirely with the keyboard:

  • Tab Navigation: Press Tab to move between different controls and panels
  • Enter/Space: Activate buttons and checkboxes
  • Arrow Keys: Navigate within lists and select items
  • F6: Toggle accessibility features on/off (if enabled)

Keyboard navigation works throughout the entire application, including:

  • Library browsing and track selection
  • Deck controls and playback
  • Effects and mixer controls
  • Preferences and settings

Tip: Use the Tab key to navigate between UI elements. Focus indicators will help you identify which element currently has keyboard focus.

Configuring Accessibility Settings

Access accessibility features through:

  1. Go to Preferences > Accessibility
  2. Enable text-to-speech announcements
  3. Configure deck naming conventions

Key Accessibility Options:

  • Announce Track Selection: Speak artist and title when tracks are selected
  • Announce Track Load: Speak track details when loaded to a deck
  • Announce Cue Button: Announce cue on/off states
  • Deck Naming Convention: Choose between "Deck 1" or "Deck A"
  • TTS Voice: Select preferred voice for announcements
  • Speech Rate: Adjust speed of spoken announcements

Enhanced Audio Feedback System

Mixxx provides detailed audio feedback for key DJ operations:

Deck-Specific Announcements:

  • Deck 1 cue on: When you activate cue mode for deck 1
  • Deck 1 cue off: When cue mode is deactivated
  • Deck 1 loaded: Track Name by Artist: When a track is loaded
  • Deck 1 playing: When playback starts
  • Deck 1 stopped: When playback is paused
  • Deck 1 end of track: When a track finishes

Accessibility Tip: These detailed announcements help you know exactly which deck's state has changed without needing to visually check the interface.

Working with Decks

Each deck in Mixxx is clearly identified in accessibility announcements:

Deck Controls:

  • Load: Use the Ctrl+L shortcut or navigate to the library and load tracks
  • Cue: Press C to toggle cue mode
  • Play/Pause: Press Space or P
  • Sync: Press S to sync tempo

Deck Announcements:

When using any deck function, you'll hear:

  • "Deck 1 cue on" / "Deck 1 cue off" for cue state changes
  • "Deck 2 loaded: Track Name by Artist" when tracks are loaded
  • "Deck 1 playing" / "Deck 1 stopped" for playback state

Library and Track Management

The library panel provides comprehensive keyboard navigation:

Library Navigation:

  • Arrow keys: Navigate through tracks and folders
  • Enter: Select a track or folder
  • Tab: Move between library sections
  • Search: Type to filter tracks in the search bar

Library Announcements:

  • "Selected: Track Name by Artist" when tracks are selected
  • "Library focus: Sidebar" / "Library focus: Track list" when navigating panels
  • "Current search query: [search text]" when typing in search

Effects and Mixer Controls

Effect and mixer controls are fully accessible:

Accessing Effects:

  • Tab Navigation: Move between effect units
  • Enter/Space: Activate or deactivate effects
  • Arrow Keys: Adjust effect parameters

Mixer Announcements:

  • "Master volume set to [value]" when adjusting main volume
  • "Deck 1 volume set to [value]" when adjusting individual deck volume
  • "Deck 1 filter [on/off]" when using filter effects

High Contrast and Visual Settings

For users with low vision:

High Contrast Themes:

  • Enable in Preferences > Interface
  • Provides better visibility for screen readers
  • Improves contrast for visually impaired users

Customizable Options:

  • Font size adjustments through system preferences
  • Dynamic color themes for different lighting conditions
  • Keyboard focus indicators that are clearly visible

Technical Support and Troubleshooting

If you encounter accessibility issues:

Common Solutions:

  • Ensure keyboard navigation is enabled in preferences
  • Test with screen reader software for full compatibility
  • Adjust TTS voice and rate settings for optimal comfort
  • Check that proper deck naming convention is selected

Getting Help:

  • Visit the Mixxx Support Portal
  • Join the Mixxx Community Forum for user discussions
  • Report accessibility issues through the GitHub issue tracker
